# 🩺 Real-Time Nail Disease Detection System

## 📌 Overview
This project is a **Real-Time Nail Disease Detection System** that uses Deep Learning (YOLO) to detect and classify nail diseases from images or live webcam input. It helps users identify possible nail conditions at an early stage.

---

## 🚀 Features
- Real-time nail detection using webcam  
- Image upload support  
- AI-based disease classification using YOLOv8  
- Displays disease name with confidence score  
- Provides basic precautions and suggestions  

---

## 🛠️ Tech Stack
- Frontend: Streamlit  
- Backend: Python  
- Model: YOLOv8 (Ultralytics)  
- Libraries: OpenCV, NumPy, Pandas

## 🧪 How It Works
1. User uploads an image or uses webcam  
2. The YOLO model processes the image  
3. The system detects the nail region  
4. Disease is classified and displayed with confidence score
