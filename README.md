🩺 Real-Time Nail Disease Detection System
📌 Overview

This project is a Real-Time Nail Disease Detection System that uses Deep Learning (YOLO) to detect and classify nail diseases from images or live camera input.
The system helps users identify possible nail conditions and provides basic insights for early awareness.

🚀 Features
🔍 Real-time nail detection using webcam
🧠 AI-based disease classification (YOLO model)
📸 Image upload support
⚡ Fast and accurate predictions
📊 Displays detected disease with confidence score
💡 Provides basic precautions and suggestions
🛠️ Tech Stack
Frontend: Streamlit
Backend: Python
Model: YOLOv8 (Ultralytics)
Libraries: OpenCV, NumPy, Pandas

🧪 How It Works
User uploads an image or uses webcam
The YOLO model processes the image
The system detects nail region and classifies disease
Output is displayed with label and confidence score
